## 🌿 Leaf Area Estimation using Deep Learning

**Python • YOLOv8 • OpenCV • Roboflow • Computer Vision**

An end-to-end computer vision pipeline for estimating real-world leaf area from RGB images.

* 🌱 Collected a custom leaf dataset and manually measured ground-truth areas.

* 📸 Annotated images using **Roboflow**.

* 🎯 Fine-tuned **YOLOv8** using Kaggle and custom datasets.

* 📐 Implemented perspective correction and geometric calibration.

* 🔴 Used a fixed **16 cm² reference strip** for pixel-to-centimetre scaling.

* 🍃 Developed a multi-stage pipeline:

  `Tray Detection → Perspective Correction → Calibration → Leaf Detection → Segmentation → Area Estimation`

* 📊 Compared predicted leaf areas against manually measured ground truth for validation.
